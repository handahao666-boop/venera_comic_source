## 如何收到更新

Venera 的「漫画源 → 漫画源列表 → 仓库地址」应指向：

https://raw.githubusercontent.com/handahao666-boop/venera_comic_source/main/index.json

源内 url 指向单个 JS 原始文件，仓库地址指向 index.json，两者用途不同。客户端从索引按 key 比较版本，更新时才从已安装源 url 下载文件；若仍配置官方或其它仓库索引，不能指望发现本仓库独有版本。旧源 url 为空或指向其它作者仓库的用户，应先手动导入本仓库对应 JS 一次。后续升级需同步提高源文件和索引版本。

仓库提交不是实时推送；由客户端启动检查或手动「检查更新」发现。使用 jsDelivr 镜像时，缓存可能延迟显示更新。
