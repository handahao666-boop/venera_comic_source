# 爱看漫 3.0.1 更新记录

2026-11-27。以用户提供并反馈已修好的桌面文件为发布基础。

## 更新内容

- 首页按新版分区和卡片结构解析作品，支持从图片元素读取封面，并合并重复作品。
- 详情页直接读取章节链接，适配新版标题、封面、简介、作者、更新信息及推荐作品。详情加载省去书柜请求。
- 章节图片分页先获取总数，再以最多四个并发请求加载后续分页，并按页序合并。
- 地区限制提示支持简繁中文和英文。
- 发布版将脚本更新地址指向本仓库，版本保持用户文件中的 3.0.1。

## 安装与后续更新

文件名为 `ikmmh_v2.js`，源标识为 `ikmmh_v2`。仓库索引和脚本版本均为 3.0.1。[仓库版脚本](https://raw.githubusercontent.com/handahao666-boop/venera_comic_source/main/ikmmh_v2.js)

旧版脚本的更新地址指向漫画网站首页。已安装旧版时，需要在 Venera 的源编辑页把 `url` 改为上述脚本地址，重载后点击更新，或重新导入仓库版。已导入用户桌面 3.0.1 的客户端，也需要切换到这个仓库地址，才能下载后续版本。

## 验证记录

- 响应回放使用新版结构样本检查首页分区、详情、章节链接、搜索、分类和图片分页的结果及顺序。此项属于模拟响应验证。
- 真网请求公开首页和作品详情均收到 HTTP 403，正文为地区限制提示，当前测试网络未完成真网内容回归。
- 用户反馈桌面版已修好。本轮未在 Venera 客户端中重新安装和实测仓库版。
