# 拷贝漫画 1.6.13 发布记录

2026-11-27。发布用户指定的本地修复版，与桌面「拷贝漫画_1.6.13.js」内容一致。

## 本次更新

- 默认访问入口使用 App 接口，基础地址为 `api.copy2000.online`。访问入口设置中仍可手动选择官网桌面网页。
- 手动填写的 API 地址按该地址请求。填写 `auto` 时使用自动发现线路。
- 官网网页连接失败时，会提示可以切换至 App 接口。

## 更新方法

仓库脚本和索引均为 1.6.13，文件名为 `copy_manga.js`，源标识为 `copy_manga`。更新地址指向本仓库。[脚本下载](https://raw.githubusercontent.com/handahao666-boop/venera_comic_source/main/copy_manga.js)

已使用仓库更新直链的源，可在 Venera 的「漫画源 → 检查更新」中获取新版。此前版本仍指向上游仓库时，可编辑脚本 `url` 为上述下载地址并重载，再点击更新，或重新导入仓库版。

新版默认值适用于没有保存过该选项的安装。已选择「官网桌面网页」的用户，更新后请在「源设置 → 访问入口」手动选择「App 接口」。
