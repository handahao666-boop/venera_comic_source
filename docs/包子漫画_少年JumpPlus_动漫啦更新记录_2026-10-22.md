## 包子漫画 1.1.7（非镜像）

- 保留原有 App 阅读页入口；入口失败时，增加所选网站的网页阅读入口作为备用。
- 正文按原站同一作品、同一章节的分页链接完整获取，合并分页重叠图片并保持顺序，避免只显示首批 50 张。
- 校验分页编号、总页数、循环和后续页内容；后续页失败会明确报错，不把部分章节当成完整章节，也不会把下一话接到本话。
- 正文页面请求使用不缓存策略；保留登录、网站书架、简繁体、CDN 和图片质量设置。默认 640p，可切换原图。
- 本次只更新 key 为 `baozi` 的源，不发布独立镜像版。

回归：使用 2026-10-20 保存的匿名原站响应复跑，《我独自升级》序章与第 1 话分别为 120 / 118 张；标准版 App 入口和模拟 App 入口失败后的网页备用入口，均取得相同数量与顺序。此前完成 8 张边界图片及标准版 640p 样本的完整解码。本次未验证真实账号登录和网站书架。

## 少年 Jump+ 1.2.0

- 解决 App 令牌接口返回 HTTP 403 HTML 后，被旧源当成 JSON 解析而报 `unexpected token: <` 的问题；新版改读官网公开网页与网页阅读器目录接口。
- 恢复最近七天更新、连载/短篇/完结分类、作品搜索、完整分页目录和公开免费章节。
- 目录保持从早到晚的顺序；短篇、完结大列表按每个显示页 50 部展示，正文图片数量不受此限制。
- 使用 Venera 图片脚本还原官网正文拼块，保留边缘像素，封面不作拼块处理。
- 页面与目录每次加载重新请求；HTTP 错误、HTML 错误页、目录缺页均提供明确提示。

回归：14 组检查复跑通过，其中 13 组使用 QuickJS 与官方 Venera 初始化脚本，大分类一组使用 Node VM 与同一初始化脚本。保存响应中的首页为 7 个分区、56 条展示；SPY×FAMILY 目录 182 章、4 页；第 1 / 2 / 141 话分别为 71 / 55 / 23 张。此前完成 10 张图片完整解码和 9 张正文还原核验。

兼容说明：保留源 key，但官网和旧 App 的作品、章节 ID 不完全相同。旧收藏或历史打不开时，需要重新搜索作品、打开新目录并重新收藏。本版支持官网匿名公开内容，未提供登录和账号已购内容支持；官网要求权限的章节会明确提示。此次修复不表示旧 App 接口的 403 已解除。要求 Venera 1.6.0 及以上。

## 动漫啦 1.0.5

- 修复发现页只显示“推荐漫画”标题、列表为空的问题；适配当前首页 `.library-section` / `a.comic-card`，同时兼容旧页面结构。
- 恢复五个首页分区、分类分页、最近更新及搜索；保留原作品、章节 ID，目录按从早到晚排列。
- 页面、目录与整话图片清单每次加载重新请求；整话阅读页取得完整图片，避免截断。
- 保留图片请求头、内容检查与有限重试，隔离旧图片缓存；连接或解析失败会明确报错。
- 沿用原文件名 `dongman_la_fixed_v101.js`，文件内部版本号为 1.0.5。

回归：13 组 QuickJS 检查复跑通过。保存响应中的首页为 62 部；《一拳超人》目录 263 条；长章节完整返回 131 张图片。此前完成 11 次页面请求及 12 张封面/正文抽样图片完整解码。本机真网验证曾使用仅对测试 curl 进程生效的 DNS 解析覆盖，仍验证 HTTPS 证书；交付源未写固定 IP，未改变系统网络设置。不同网络仍可能遇到连接问题。

## 更新与验证范围

1. 在 Venera 漫画源管理中刷新仓库列表，更新这三个已有源，确认版本号与上表一致。
2. 重新打开或刷新首页、作品目录和章节。已离线下载成半章的旧包子章节需要重新下载。
3. 漫画内容在打开或刷新时从网站获取；收藏后台检查频率由 Venera 设置决定，不是本源在后台定时推送。

发布副本仅将换行统一为 LF，功能代码与此前通过真网验证的交付文件一致；本次对发布副本重新运行现有离线/模拟回归，没有将复跑表述为新增一轮真网测试。没有原生客户端 UI 或实体手机验收。抽样图片通过不代表已逐张下载所有章节。
