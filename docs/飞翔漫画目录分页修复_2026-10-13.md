# 飞翔漫画目录分页修复

日期：2026-10-13。源文件：`ffppt.js`，版本：1.0.2。

## 问题与修复

旧版只请求 `/novel{id}/`，读取第一页的 `#list-chapter`，没有访问目录分页。网站每页最多显示50个章节条目，因此长篇作品被截断到50条。

新版从本作品的分页导航取得页数，访问 `/novel{id}/?p=N` 并合并所有页面。最多同时请求4页，合并时保留网站顺序、按章节ID去重；不写死50章或固定页数。后续页面如果显示新尾页，会继续读取。

详情及目录分页请求使用 Venera 的 `cache-time: no`，每次加载或刷新时重新请求当前网站目录。分页HTTP错误、网络错误、空目录、缺失目录、返回错误页或完整重复页都会报错，不把已加载的部分目录当作完整结果返回。所有解析文档均释放。

此处记录的1.0.2目录修复已包含在1.0.3中；仓库的 `index.json` 和 README 源清单同步为1.0.3。

## 实际网站核验

通过只读GET抓取全部页面，保存原始HTML，并用独立DOM解析逐页对照源返回的章节ID、标题和顺序。核验后另做保存页面回放，确认抓取页数等于网站分页导航声明的页数。

| 作品 | 网站目录页数 | 旧版条目数 | 修复版条目数 | 末条目录 | 末章图片地址数 |
| --- | ---: | ---: | ---: | --- | ---: |
| 武炼巅峰（27073） | 79 | 50 | 3945 | chapter3944：3877 寻找救援 | 75 |
| 中国惊奇先生（神鬼七杀令）（27042） | 37 | 50 | 1846 | chapter1845：1835 第14季開啓(1\\/2) | 50 |
| Foundnotes（31602） | 1 | 1 | 1 | chapter0：第1话 | 7 |

表中数量是网站目录条目数，标题中的话数可能与条目数不同。旧版《武炼巅峰》另用修改前文件回放，复现仅1次目录请求、50条结果。

本次联网目录与末章请求耗时约44秒、22秒和3秒，取决于网络及目录长度。图片验证是末章图片地址解析，不代表已在手机逐张显示全部图片。

## 回归检查

使用本地 Venera JavaScript 初始化代码与 HTML/网络桥接，按客户端1.6.3运行源。11项专项检查通过：单页和章节0；跨页去重与网站顺序；并发上限和请求乱序完成；后续页新增尾页；排除推荐章节和其他作品分页；HTTP失败；网络异常；缺失目录；空目录；站点忽略分页或返回重复目录；重新加载出现新章节。错误场景均不返回部分目录，并确认文档释放。

三个网站样本的全部章节ID、标题及顺序均一致。源码语法检查和本次修改文件的Git空白检查通过。尚未在用户的手机Venera界面实际验证。

核验资料位于工作区 `update_audit/ffppt_pagination_2026-10-13/`，包含 `verify.js`、`results.json`、`replay_results.json`、旧版复现结果、逐页HTML和章节清单。复验命令：

```powershell
node update_audit/ffppt_pagination_2026-10-13/verify.js --replay
```

## 使用

在 Venera 中导入修复后的 `ffppt.js`，覆盖同名飞翔漫画源，确认版本为1.0.2。重新打开作品详情并刷新目录。长篇需要读取全部分页，请等待加载完成；若某页网络失败，按报错重试。
