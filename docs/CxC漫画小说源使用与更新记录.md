## 如何更新

1. 在 Venera 的漫画源管理中，打开已有 CxC 源的“编辑”。
2. 用本文件夹 `cxc.js` 的全部内容覆盖原脚本，保存并重新加载。
3. Windows 如果弹出 `Reload Configs`，点击 `continue`；确认源版本为 **0.2.2**。
4. 打开“小说更新”或分类页的“小说题材”。搜索小说时，把“作品类型”改为“小说”。

首次安装可直接从本地文件导入 `cxc.js`。通过编辑已有源继续使用同一个 `cxc` 标识，可延续原书架关联及本地账号数据。

## 源内小说阅读

Venera 的源接口接收图片页。本版在 Venera 的计算接口中完成文字排版，生成可由阅读器显示的 PNG 页；没有在电脑上运行额外的服务。原站章节提供的字库负责还原其特殊字形，Noto 字库补齐普通汉字。

**第一次阅读小说需要下载基础字库，约数 MB。** 同一源实例会复用基础字库，字库请求也允许客户端缓存。切换到另一种繁简字形时，可能需要下载对应字库。基础字库从 Noto 官方仓库获取，并设有 CDN 备用地址；章节字库从 CxC 获取。若字库下载失败，源会给出错误，可检查网络后重新打开章节。

正文以图片页呈现，阅读器中的缩放和翻页可以使用；排版字号在本源设置中调整。本版没有接入正文选词复制、音声和配音。外链插图或字库未覆盖的字符会明确报错，不会将缺失内容当成完整正文返回。

## 登录及权限

继承 0.1.1 的网页登录和会话导入方式：在源登录页点击“网页登录 / Login with webview”，在 CxC 官网选择 Google 或其它实际使用的登录方式，等待“CxC 官网会话已验证”提示，再查询“账号与分级状态”。

如果 Google 不允许在内置浏览器登录，可在常用浏览器正常登录 CxC，然后从开发者工具的“应用（Application）→ Cookie → https://cxc.today”复制 `cxc_access_token` 和 `cxc_refresh_token` 的值，填入源登录页两个同名字段并继续。会话只在本地填写，不需要发送到聊天中。

年龄分级默认关闭；开启账号分级内容仍要求官网账号的生日、成人模式和源设置满足条件。购买、租用、订阅和其它阅读权限由官网决定。仅对官网实际授权返回的正文进行排版，“含免费章节”不等于全本免费。

## 动态更新

列表、搜索、作品详情和目录均重新请求官网 API。每次重新打开小说章节，也重新请求当前正文；内存中的排版结果用于同一次阅读翻页，不能代替再次打开章节时的请求。

正文或字号、字形、配色变化后，图片缓存标识随之变化，防止旧图片挡住新内容。应用重新启动后，也能依据已有页面标识重新取得章节及字库；若正文已改变，则提示刷新章节。源没有常驻后台轮询，书架检查与通知由 Venera 设置控制。
