# 飞翔漫画 1.0.7 更新记录

## 封面与正文

- 最近更新优先检查原封面。原封面失效时，使用同一作品的公开章节首张可用图片作预览。后续条目在后台补图，刷新后可以看到已取得的图片。
- 正文使用已验证的 HTTPS 图床地址，并按原站阅读方式请求瓜子图床图片。
- 原站图片文件缺失时保留原页码，客户端仍会显示该页加载失败。

## 验证

在 Windows Venera 1.6.3 打开飞翔漫画首页并刷新，确认此前封面报错的《安吉拉：仙宫刺客Avengers NOW!》《快乐巧克力》《Trouble Click!!》《会心一击！》已显示图片，最近更新后段的封面也能显示。真网模拟在后台补图结束后，为当时最近更新的 20 项取得了可用图片地址，抽查解码了 7 张推荐封面和最近更新前 8 项的图片。另抽查《兔大人别撩我》和《花是诱饵》的正文。

## 更新方法

旧仓库版 1.0.3 的脚本没有更新地址。如果在 Venera 点更新时看到 `Invalid url config`，请手动切换到仓库版一次。也可以在旧源的编辑界面把 `url` 设为下方脚本直链，保存并重载后点更新。

- [飞翔漫画 1.0.7 脚本](https://raw.githubusercontent.com/handahao666-boop/venera_comic_source/main/ffppt.js)
- [Venera 仓库索引](https://raw.githubusercontent.com/handahao666-boop/venera_comic_source/main/index.json)
