# 哔哩漫画 1.2.3 更新记录

2026-11-26

- 原站要求搜索验证时，Venera 会显示原站图片，并在同一会话中提交用户手动输入的四位验证码。验证未通过时会显示新图，可再输入一次。关闭弹窗会取消这次搜索。
- 搜索列表使用原站返回的下一页链接。只有一条结果时，仍可从跳转后的作品详情页显示该结果。
- 网络握手中断时，支持备用 HTTP 客户端的 Venera 版本会重试一次。原站限流和验证错误会显示对应提示。

## 安装与更新

源标识为 `bilimanga`。仓库索引和脚本均为 1.2.3。通过仓库安装这个版本后，可在「漫画源」中检查后续更新。[1.2.3 下载](https://raw.githubusercontent.com/handahao666-boop/venera_comic_source/main/bilimanga.js)

旧版和此前桌面测试版的脚本更新地址为空。可在 Venera 的源编辑页把脚本里的 `url` 填为上述下载地址，重载后点击该源的更新按钮。也可用仓库版重新导入一次。
