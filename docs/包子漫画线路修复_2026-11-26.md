# 包子漫画 1.2.1 更新记录

2026-11-26

## 线路与页面修复

- 主域名列表将 `webmota.com` 放在首位作为默认线路。简体模式下，选择 `baozimhcn.com` 或 `bzmgcn.com` 时，请求使用 `webmota.com`。繁体模式下，这两个选项仍使用各自的繁体线路。其余三个选项 `kukuc.co`、`twmanga.com` 和 `dinnerku.com` 按所选域名发出请求。
- 源设置新增「原站网页验证 → 在浏览器打开」，可打开原站首页并在浏览器内完成原站要求的验证。
- 首页遇到 HTTP 403 或返回无法识别的列表时，会明确显示错误。作品详情缺少作者字段时仍可加载。登录、退出和注册使用实际选中的线路。

## 安装与更新

仓库索引和脚本均为 1.2.1，源标识为 `baozi`。已使用本仓库更新地址的客户端，可在 Venera 的「漫画源 → 检查更新」获取新版。[更新索引](https://raw.githubusercontent.com/handahao666-boop/venera_comic_source/main/index.json) · [1.2.1 脚本](https://raw.githubusercontent.com/handahao666-boop/venera_comic_source/main/baozi.js)

## 发布时的回归验证

- 响应回放复现了旧版的 HTTP 403，检查了六条域名线路在简繁模式下的 12 种配置组合，并验证原站网页入口。
- 真网使用 `baozimhcn.com` 的简体设置，请求通过默认线路完成。首页返回 7 个板块和 108 张卡片，分类返回 36 条，搜索返回 7 条。《我独自升级》获得 183 个章节，样本章节返回 120 页，抽检第 1、51、120 页图片均下载成功。其他线路未逐条完成真网阅读测试。
- Venera 实机核对了已安装源的版本与更新地址。发布时未在客户端点击「检查更新」，线上 GitHub Raw 索引和脚本均已核对为 1.2.1。
